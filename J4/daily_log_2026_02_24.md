# Daily Log: 2026-02-24 — J4: Feature Engineering Radicalement Différent

## Objectif
Tester une approche radicalement différente de J1–J3 : remplacer les tree models sur features artisanales par **PCA + Autoencoders + modèles régularisés**.

---

## 1. Pipeline Pure (Raw → PCA/AE → LogReg)
*Fichier: `run_pipeline.py`*

- **Principe** : 42 features brutes → PCA (30 comp, 89.3% variance) + Autoencoder PyTorch (latent=30) → Logistic Regression (L1/L2/ElasticNet)
- **Résultats (sample, 3 trials Optuna)** :
  - Val: **0.5164** ±0.0026 | Gap: 0.008 | Best: L2, C=2.83
- **Constat** : Gap train/val quasi nul ✅, mais accuracy trop faible (proce du random)

## 2. Pipeline Hybride + LogReg (J3 features → PCA/AE → LogReg)
*Fichier: `run_hybrid_pipeline.py`*

- **Principe** : 105 features J3 (rolling stats, momentum, volatility, interactions, sign flips, volume flow, cross-lag correlation) → PCA + AE → LogReg
- **Résultats (sample, 3 trials)** :
  - Val: **0.5180** ±0.0030 | Gap: 0.007
- **Résultat LB** : Soumission → **0.5057** (quasi-random)
- **Diagnostic** : LogReg est trop faible — même avec features débruitées, un classifieur linéaire ne capte pas les interactions non-linéaires nécessaires

## 3. Pipeline Hybride + LightGBM (J3 + PCA + AE → LightGBM)
*Fichier: `j4_hybrid_lgbm_colab.ipynb`*

- **Principe** : Concatène les 3 sources de features (J3 originales + PCA + AE latent = ~159 features) et utilise LightGBM comme classifieur
- **AE entraîné une seule fois** (pas dans Optuna) pour éviter le coût GPU
- **Résultats (full data, 30 trials Optuna, Colab GPU)** :
  - Val: **0.5215** ±0.0021 | Train: 0.5386 | Gap: 0.017
- **Feature Importance** (top 10) :
  1. MEDIAN_DAILY_TURNOVER (264)
  2. RET_7 (201)
  3. MOM_MA_1_5 (179)
  4. RET_2 (168)
  5. SHARPE_PROXY_20 (151)
  6. RET_8 (142)
  7. RET_1 (140)
  8. RET_MEAN_20 (129)
  9. **AE_11** (105) ← autoencoder feature
  10. **AE_2** (91) ← autoencoder feature
- **Constat** : AE et PCA apportent un complément utile (dans le top 20), mais le signal principal reste dans les features J3. LB en attente.

---

## Enseignements Clés

| Approche | Val Acc | Gap | LB |
|---|---|---|---|
| J4 Pure (PCA/AE → LogReg) | 0.5164 | 0.008 | — |
| J4 Hybrid (J3 → PCA/AE → LogReg) | 0.5180 | 0.007 | 0.5057 |
| J4 Hybrid (J3 + PCA + AE → LightGBM) | 0.5215 | 0.017 | En attente |
| J3 Baseline (J3 → LightGBM) | ~0.53 | ~0.02 | ~0.51 |

1. **LogReg est inadapté** pour ce problème : même avec des features débruitées, le classifieur linéaire ne détecte rien
2. **PCA/AE en remplacement** des features artisanales = perte de signal. Le domain knowledge (momentum, volatility ratio, money flow) est irremplaçable
3. **PCA/AE en complément** = léger gain. Les features AE_11, AE_2 apparaissent dans le top 10 du LightGBM
4. L'approche la plus prometteuse serait le **stacking** : utiliser les OOF predictions de ce modèle J4 comme meta-feature dans un ensemble
